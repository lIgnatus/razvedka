# Социокультурная разведка: сайт

Статический сайт для GitHub Pages. Его задача — увлечь историями Альшеевского района и бывшего Белебеевского уезда и показать перспективы развития.

На сайте:

- видео с дрона над Сусактау на первом экране, такое же, как на туристическом портале;
- программа 17 и 18 октября 2026;
- истории 27 мест трёх районов: Альшеевского, Давлекановского и Белебеевского;
- карта со всеми местами;
- десять культурных пластов;
- полоса с видео долины Дёмы;
- перспективы развития;
- мероприятия по месяцам и фильмы;
- мотивация и сервис;
- контакты с QR-кодами.

Сборка не нужна: это обычные файлы HTML, CSS и JS.

## Как выложить на GitHub

1. Создать на GitHub новый репозиторий, например `razvedka`. Тип: Public.
2. Загрузить в корень репозитория **содержимое** этой папки, а не саму папку: `index.html`, `.nojekyll`, `README.md` и папки `assets` и `files`.
   - Через сайт: Add file → Upload files, перетащить всё и нажать Commit changes.
   - Файл `.nojekyll` скрытый: включите в проводнике показ скрытых файлов, иначе он не загрузится. Без него сайт тоже работает.
   - Видео занимают 11,5 МБ, весь сайт около 22 МБ. Это в пределах ограничений GitHub.
3. Settings → Pages → Source: Deploy from a branch, ветка `main`, папка `/ (root)`, Save.
4. Через минуту сайт откроется по адресу `https://<логин>.github.io/razvedka/`.

## Как устроено

| Файл | Что это |
|---|---|
| `index.html` | Страница: разделы и их порядок |
| `assets/js/data.js` | Все тексты: программа, пласты, места, перспективы, фильмы, мероприятия, контакты, источники. Править здесь |
| `assets/js/app.js` | Сборка страницы: видео, программа, карточки, карта Leaflet, панели мест и пластов, кнопка «Назад», QR-коды |
| `assets/js/districts.js` | Границы трёх районов из OpenStreetMap |
| `assets/css/style.css` | Оформление в стиле полевого журнала, отдельная проработка под телефон |
| `assets/img/` | Фото |
| `assets/video/` | Три ролика с дрона: 1080p для компьютера, 720p для телефона, плюс постеры |
| `files/` | PDF программы для скачивания |

**Как написана история места.** Каждое место в `R.places` состоит из частей:

- `hook`: зацепка, одна строка, например «Гора старше динозавров»;
- `lead`: вступление;
- `story`: рассказ по частям, `[заголовок, текст]`;
- `events`: какие мероприятия проводят;
- `next`: перспективы;
- `legend`: легенда.

Новое место добавляется по образцу соседних записей. Обязательны поля:

- `id`;
- `n`: название;
- `d`: район, `a`, `d` или `b`;
- `ll`: широта и долгота;
- `L`: пласты.

Точка сама появится на карте, в списке и в карточках.

**Ссылка на место или пласт.** Можно дать прямую ссылку, например `…/#mesto/deev` или `…/#plast/lt`.

## Телефон

- Внизу экрана панель разделов: Программа, Истории, Карта, Пласты, Контакты. Меню открывается на весь экран.
- История места открывается на весь экран, сверху кнопки «Назад» и «Закрыть».
- Системная кнопка «Назад» телефона закрывает панель или меню и не уводит со страницы. Из места, открытого внутри пласта, «Назад» возвращает к пласту.
- Карта не перехватывает прокрутку страницы. Двигать её можно после касания по кнопке «Нажмите, чтобы двигать карту». Когда карта уходит с экрана, она снова закрывается.
- Карта создаётся только при подходе к ней. Ролики загружаются в 720p и ставятся на паузу, когда их не видно. Так страница не тормозит.
- В режиме экономии трафика видео не загружается, вместо него показан постер.

## Фото

- **Свободные фото.** Снимки с Wikimedia Commons идут со свободными лицензиями. Открытки и портреты: общественное достояние. Снимки организаторов: «РАЕВские встречи», съёмки и афиши LifeStyle Cinema, видео и фото Сусактау из архива портала.
- **Фото из реестра.** По просьбе заказчика добавлены фото из реестра «Что посмотреть»: Яндекс Карты, Культура.РФ, ВКонтакте, National Geographic Россия, управление культуры Давлекановского района, Reki-Ozera.ru. У каждого снимка подписан источник. Свободной лицензии у этих фото нет, поэтому на публичном сайте лучше получить согласие авторов или заменить фото своими.
- **Журнал.** PDF «Полевого журнала разведки» на сайт не выложен, он отправляется гостям отдельно.

## Как посмотреть локально

Можно открыть `index.html` двойным щелчком. Если с диска не загрузится подложка карты (некоторые серверы карт так не отдают тайлы), запустите в этой папке простой сервер, например `npx serve`, и откройте показанный адрес.
